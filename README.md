# 图鉴解锁方案 CodexHint（Survival Log MOD）

> 作者 Night · 抖音 166660371 · 免费分享 · 只读增强：不解锁条目 / 不改存档 / 不改游戏文件

## 一、这是干什么的

游戏自带的「生存图鉴」对未解锁条目只显示剪影和一句泛化提示（"尝试食用获取该条目"），右侧详情面板一片空白，玩家不知道缺的是什么、去哪补。

装上本 mod 后，点开任意未解锁条目，右侧直接列出**该条目的具体获取途径**：

- 食物：灾前哪家超市哪个货架有售、哪张地图能捡、种植什么能收
- 菜肴：烹饪哪道配方、需要什么食材和烹饪等级
- 植物：种子去哪买、种下后怎么收
- 猎物：用哪种陷阱捕、哪张地图随机遇到
- 制造：需要哪些材料、制造等级门槛
- 家具：家具商店第几页、制造什么包裹后放置、完成哪个事件获得
- 装修：制造或获取装修道具后使用

## 二、方案数据怎么来的

启动时从游戏内存里的配置表**运行时推导**（商店货架、配方、事件奖励、地图容器、陷阱、种植等十余类来源反查），不内置任何静态数据——**游戏更新加新物品后自动跟随**，无需更新 mod。

所有文案按游戏内实际机制实证撰写：灾前限时商店标「灾前」（这些商店灾变后关闭）、灾后探索图标「野外探险」、联系人支援/交易、无人机据点交易、援助委托分别标注，不会出现内部代码或看不懂的池名。

## 三、使用

- 装好即生效，无需设置；打开图鉴 → 点未解锁条目即可看到「解锁方案」列表。
- 总开关 `General.Enabled`（BepInEx 配置 / ModCenter 面板）：关闭后停止注入，重开图鉴恢复官方原样。
- 查不到可靠途径的条目（极少）不显示方案，保持官方原样，不编造。

## 四、兼容

- 适配游戏 2026-11 版（GameAssembly 与图鉴界面 DOM 变更可能导致面板静默缺席，不影响游戏）。
- 零 Harmony、不写存档；与其他套件 mod 无冲突。
